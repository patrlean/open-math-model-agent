# MCM/ICM Excellent Paper Writer

这是一个面向美国大学生数学建模竞赛 MCM/ICM 的论文写作 Skill，重点覆盖：

- 一页 Summary Sheet；
- task-driven 论文结构；
- 文献、数据、假设和符号；
- 评价、动力学、网络、优化、预测和概率模型；
- 模型验证、敏感性和情景分析；
- Policy Recommendations 与 Memo；
- References、Appendix 和 AI 使用披露；
- 英文表达与最终一致性检查。

## 使用方式

将整个文件夹作为一个 Skill 加载，核心指令位于 `SKILL.md`。

加载后会激活美赛论文页数档案：官方上限 25 页，写作目标 25 页，24–25 页可以验收。

可使用的辅助模板：

- `templates/summary-sheet-template.md`
- `templates/memo-template.md`
- `checklists/final-checklist.md`

## 推荐输入

提供赛题、附件数据、已有代码、已得到的数值结果、当年官方格式和需要提交的额外文档。缺少结果时，Skill 会保留明确占位符，而不是虚构数字。
