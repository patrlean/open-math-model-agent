# MCM/ICM Final Checklist

## Summary Sheet

- [ ] One page under the current official format.
- [ ] All tasks are covered.
- [ ] Each task has method + result + implication.
- [ ] Key numbers match the body.
- [ ] Validation and final recommendation are included.
- [ ] Keywords are specific.

## Structure

- [ ] Task dependency is clear.
- [ ] Model names are descriptive and consistent.
- [ ] Workflow figure matches section structure.
- [ ] Required Memo/Letter/Report is included.

## Data

- [ ] Every external dataset has a source.
- [ ] Time, location, sample size and units are stated.
- [ ] Missing values and outliers are handled.
- [ ] No train-test leakage exists.

## Models

- [ ] Every model has a real-world mechanism.
- [ ] Variables are defined before use.
- [ ] Parameters are observed, estimated, cited or labeled assumed.
- [ ] Objectives and constraints are explicit.
- [ ] Solver settings and stopping criteria are stated.
- [ ] Random algorithms are repeated or seeded.

## Equations

- [ ] Equation numbering is consistent.
- [ ] Units are consistent.
- [ ] Probability and weights stay within valid ranges.
- [ ] Every major equation has textual interpretation.

## Results

- [ ] Every task receives a direct answer.
- [ ] Results are quantitative.
- [ ] Figures and tables are referenced before appearance.
- [ ] Captions, axes, units and legends are complete.
- [ ] No figure duplicates a table without purpose.

## Validation

- [ ] Each core model has at least one validation.
- [ ] At least two complementary validation types are used overall.
- [ ] Sensitivity parameters are important and uncertain.
- [ ] Scenario ranges are justified.
- [ ] Prediction uncertainty is reported.

## Recommendations and Memo

- [ ] Every recommendation traces back to a finding.
- [ ] Actor, action, resources, timing and effect are clear.
- [ ] Main risks and contingency plans are included.
- [ ] Memo is written for a decision maker, not as a technical abstract.

## Writing and Format

- [ ] Team identity remains anonymous except control number.
- [ ] Current-year page and submission rules are satisfied.
- [ ] Terminology and spelling are consistent.
- [ ] No duplicated sentences or contradictory numbers.
- [ ] References are real and consistently formatted.
- [ ] AI use is disclosed exactly as required.
- [ ] Appendix contains only supplementary material.
